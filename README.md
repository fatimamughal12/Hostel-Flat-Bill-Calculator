# Hostel / Flat Bill Calculator 🏠

A beginner-friendly Python mini project designed to simplify the calculation and sharing of hostel or flat expenses. The application provides a graphical user interface (GUI) to calculate rent, food expenses, and electricity charges, then divides the total bill among multiple persons.

This project was developed for learning and practicing Python GUI development, basic calculations, and PDF generation.

## ✨ Features

- **Expense Calculation:** Calculate rent, food, and electricity expenses.
- **Electricity Bill:** Calculate electricity charges based on units consumed and cost per unit.
- **Bill Splitting:** Divide the total expenses among multiple persons.
- **Bill Summary:** Display the complete bill summary in the application.
- **PDF Generation:** Download the calculated bill as a PDF file.
- **User-Friendly Interface:** Simple and dark-themed GUI.

## 🛠️ Technologies Used

- **Python** — Core programming language.
- **CustomTkinter** — For creating the graphical user interface.
- **Tkinter** — For the file save dialog.
- **ReportLab** — For generating PDF bills.

## ⚙️ Installation and Setup

### 1. Clone the Repository

git clone https:https://github.com/fatimamughal12/Hostel-Flat-Bill-Calculator.git

### 2. Open the Project Folder

cd Hostel-Flat-Bill-Calculator

### 3. Install Required Libraries

pip install customtkinter reportlab

### 4. Run the Application

python Rent_calculator.py

## 📖 How to Use

1. Enter the hostel or flat rent.
2. Enter the total food expenses.
3. Enter the electricity units consumed.
4. Enter the electricity charge per unit.
5. Select the number of persons sharing the expenses.
6. Click **Generate Bill** to calculate the total and per-person amount.
7. Click **Download Bill** to save the bill as a PDF.
